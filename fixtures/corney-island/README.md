# Corney Island v0.3 golden fixture

Ergogen's output for Corney Island v0.3, the reference that layout acceptance (initiative C4) is measured against. Everything under `source/` and `ergogen/` is generated by `generate.sh` and committed unmodified, except that the script drops `ergogen/outlines/_debug_points.yaml` (8.5 MB of debug data nothing reads; its `.svg` and `.dxf` are kept). Do not hand-edit it: change the script and rerun it.

`source/config.yaml` is a byte-for-byte copy of `_bmad-output/layout-model/sources/corney-island.yaml`.

## Reproduce

```sh
bash fixtures/corney-island/generate.sh
git status --porcelain fixtures/corney-island/   # expected: empty
```

The script builds everything in a temp dir and replaces `source/` and `ergogen/` only once it all succeeded. It fetches the footprints at the pinned SHA into `source/footprints/ceoloide/`, copies the config to `source/config.yaml`, clones Ergogen at tag `v4.2.1` into a temp dir (checking the commit above), installs it with `npm ci` and runs it under a clock fixed at 2026-10-23T00:00:00Z (the Corney HEAD commit date), because the KiCad 8 template stamps each PCB with today's date:

```sh
node --import <fixed-clock.mjs> <ergogen>/src/cli.js source -o ergogen --debug --clean
```

Ergogen runs from source because its lockfile pins the GitHub-hosted deps by commit (`hull` `5847b0a4fa23f8e5aa3c37a8e6d7b8cf58f24082`, `kle-serial` `61f29f317d87bbfed0b0b7e646e1b91d4384ac02`); the npm package leaves them floating, and pnpm 12 refuses them. Nothing enters the workspace lockfile. The lockfile fetches them over `git+ssh`, so GitHub SSH access is needed.

## Design to file map

Both designs come from the one run. They share `points` and differ only in the PCB.

| Design     | Key poses                    | PCB                                             |
| ---------- | ---------------------------- | ----------------------------------------------- |
| `wired`    | `ergogen/points/points.yaml` | `ergogen/pcbs/corney_island.kicad_pcb`          |
| `wireless` | `ergogen/points/points.yaml` | `ergogen/pcbs/corney_island_wireless.kicad_pcb` |

Keys are the points tagged `key` (18 matrix + 3 thumb). Points tagged `helper`, `underglow` or `screw` are not keys. Coordinates are Ergogen's frame: mm, y up, rotation in degrees.
