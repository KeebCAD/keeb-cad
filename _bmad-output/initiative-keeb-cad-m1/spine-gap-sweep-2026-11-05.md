## G. AD-17 expressions and parameters
- ✅ G1 Parameter items (14.2, 14.5; closes the `ItemId` breadth part). **Sergii: A** — `{ name: ParameterName, value: Expression }`; `ParameterName` its own schema (a letter, then letters, digits or `_`; never `-`), unique, the item's key; unit derived from the evaluated expression, never stored; `ItemId` widens to include `ParameterName`.
- ✅ G2 Grammar and units (14.2, 15.2). **Sergii: A** — standard precedence, left-associative, unary minus, parentheses, whitespace between tokens (G5's literals unchanged); `+`/`−` need equal units; unitless × or ÷ a quantity keeps its unit; unit × unit and unit ÷ unit are `unit-mismatch`; a unitless result for a length or angle field is `unit-mismatch`; division by zero is an evaluation failure (G3).
- ✅ G3 Bad expressions (14.2, 14.5, 14.4). **Sergii: A** — commands refuse an expression that fails to evaluate (wrong unit, unknown name, division by zero, negative length) with a model rejection, including a parameter edit that would break any dependant (naming them); the field keeps its last valid value; a loaded file reports the violation (`unit-mismatch`, `unresolvable-reference`, `negative-length` as error) and the affected nodes are not placed.
- ✅ G4 Parameter cycles, rename, delete (14.2). **Sergii: A** — a parameter loop is F2's cycle rejection naming the parameters in order; the violation kind `anchor-cycle` is renamed `dependency-cycle` (covers both; affects F2, I1, 13.3); a rename to an existing or invalid name is a model rejection, a valid one rewrites every use; a delete is refused while used, its ids naming the using node ids and `meta` for the gap.
- ✅ G5 The literal-only expr stub (13.17, 13.2). **Sergii: A** — only `-?digits(.digits)?` immediately followed by lowercase `mm` or `deg` (no space, `+`, exponent, leading `.`, or unitless number); returns `Result<{ value, unit }, ParseError>`.
- ✅ G6 Units before 14.2 (13.2). **Sergii: A** — a quantity field's schema refuses a literal of the wrong unit (a check from its `quantity(unit)` metadata): `input-invalid` or `design-invalid` at its path; `negative-length` waits for 14.2's evaluator; 13.2's ticket says so.
- ✅ G7 Write-back (15.2, 15.4, 15.5). **Sergii: A** — only a top-level additive literal qualifies, with its sign (`a - 2mm` edits −2); a factor or divisor never does, so a term is appended; the resulting literal rounds half away from zero to 0.01 mm or 0.1°; printed shortest decimal, no trailing zeros, never `-0`, never an exponent (G5); a term rounding to zero is removed.
