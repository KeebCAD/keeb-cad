- (event) Created from prd-keeb-cad-m1 (final, aligned with architecture 2026-10-25) and architecture-keeb-cad-layout-model (final, adopted companion). Recorded as active_initiative.
- (requirement) R1 (FR-1): build a layout from a blank canvas with groups and slots placed by anchor + offset (offset, then rotate about pivot); any node anchors to any node; moving a node moves everything anchored to it, transitively.
- (requirement) R2 (FR-2): arrange children freely or as a chain; Corney Island's cumulative column stagger and 3-key thumb fan expressible without absolute coordinates; one carried rotation per node, mid-chain non-carrying turns via explicit anchor; reproduces Ergogen placement within ±0.05 mm.
- (requirement) R3 (FR-3): set pitch independently of switch type, slot size (1u, 1.5u), a key cell applied to every key, and overrides per group or part; changing the key cell updates every key's footprints; Choc v2 at 19 mm pitch expressible.
- (requirement) R4 (FR-4): design a split-reversible board (one geometry, one PCB, per-side population); split-mirrored and unibody load without a model change (editing deferred).
- (requirement) R5 (FR-5): Save As a design copy that records its source design and revision; Corney Island wireless is a copy of wired with different parts, positions and population.
- (requirement) R6 (FR-6): build named shapes from key outlines, rectangle, circle, polygon, add/subtract/intersect and offset with corner style and fillet, referencing other shapes; Corney Island's 18-vertex filleted outline and LambBT's r=150 mm circle subtraction expressible.
- (requirement) R7 (FR-7): every primitive and polygon vertex is anchored to a node, construction point or other vertex and reusable across shapes; moving a column moves exactly the vertices anchored to it.
- (requirement) R8 (FR-8): place curated catalogue parts in slots anchored to any node; M1 catalogue covers Corney Island (Choc v2 hotswap, diode, per-key and underglow LEDs, nice!nano, OLED, nice!view, TRRS, battery connector, power switch, reset, solder jumpers, M2 screws/standoffs); footprints from keeb-cad's own library with attribution.
- (requirement) R9 (FR-9): parts bring cutouts and keep-outs for plate, PCB and case; user cutouts are shapes subtracted with booleans; moving a part moves its cutouts in every output together.
- (requirement) R10 (FR-10): define several plates (Corney: switch plate, backplate, MCU cover) as shapes, updating live, each exported as DXF/SVG or gerbers.
- (requirement) R11 (FR-11): PCB edge from the outline, footprints from key cells and parts, nets and matrix derived from layout and population; moving a key updates footprints and nets; user overrides matrix rows/columns, MCU pins and LED chain order.
- (requirement) R12 (FR-12): key-cell tracks follow keys live; other connections route in the browser in the background with progress; routes saved in the design, kept while endpoints unchanged and DRC passes, only broken connections rerouted; unrouted connections always reported; design rules obeyed (power widths, module keep-outs, edge clearance); pre-routed module zone allowed; no manual trace editing.
- (requirement) R13 (FR-13): export fab-ready gerbers + drill when routing completes, gated by zero DRC errors; a KiCad project export that opens in KiCad 10 is always available as escape hatch.
- (requirement) R14 (FR-14): add a tray case from a template with parameters (wall, PCB-to-wall gap, floor, height), open it to edit its 3D operations (extrude, offset, boolean, z-position) with parameters staying in effect; follows outline and part cutouts, rebuilds in background with progress; exports STL and STEP; operation set extensible.
- (requirement) R15 (FR-15): matrix, pin mapping and ZMK physical layout derived from the design; ZMK configuration exported per design, with RGB for the wired design; firmware model neutral so QMK can be added without design changes.
- (requirement) R16 (FR-16): author the keymap (keys, layers) expressing Corney Island's own ZMK keymap and its behaviours; entries follow their keys; deleting a key deletes its entries and undo restores them.
- (requirement) R17 (FR-17): every edit propagates to all affected outputs, live or background with progress; stale results always marked; warnings for overlaps, pitch below minimum, anchor cycles, unrouted connections, DRC violations.
- (requirement) R18 (FR-18): save/open a design as one versioned file (older files migrate), browser autosave, undo/redo of every named command (one gesture = one step), stable ids so keymap entries and saved routes survive edits.
- (constraint) C1 (prd §6): browser-only; every stage including routing and case solids runs client-side, no server.
- (constraint) C2 (prd §6): stable outputs; same file reopens to the same outputs, edits change only what they must; routes saved, case solids may be cached, pure derivations recomputed.
- (constraint) C3 (architecture spine): AD-1..AD-21 bind every epic and story; a story that needs to break one goes back through bmad-architecture.
- (constraint) C4 (prd SM-1, SM-2): acceptance against Corney Island v0.3 Ergogen output within ±0.05 mm (key centres, outline vertices, plate cutouts, case dimensions); no Corney-specific shortcuts (SM-C1).
- (constraint) C5 (prd §5, FR-15): ZMK is the only firmware target; catalogue is curated, no user-imported parts.
- (constraint) C6 (prd SM-C2): routing completion never bought by loosening clearances or hiding unrouted connections.
