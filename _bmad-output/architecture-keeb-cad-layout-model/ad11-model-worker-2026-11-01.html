Rules from the reviewer gate (new in version 3)

RuleBecomes
OrderingEvery message main sends carries (epoch, seq); every post, response and derived file echoes its seq; "older" = smaller seq in the same epoch; another epoch is dropped. The revision hash stays a content identity.
Patches in the workerThe register's file is the one place that sets up Immer and also exports applyDesignPatches; loaded separately in each thread; the mirror is deep-frozen; the immer fence is unchanged.
Design bundle (AD-1, AD-8, AD-13)Routing and fingerprints leave the design file: separate files, each tagged with its design revision, saved, versioned and shared with the design and its assets as one bundle. The design file is authored-only; AD-2's derived-section writer goes away.
Derived filespipeline posts them to main with their seq; main's storage writes the bundle atomically; one not at main's latest seq is dropped.
Undo (AD-12)Each undo record keeps the routing and fingerprints current at it; undo and redo restore them with the design.
WorkersMain spawns all three and gives the model worker a port to case and to routing; to cancel case, pipeline asks main to terminate and respawn it.
Case resultsCase posts only to pipeline, which fingerprints them, keeps STEP/STL and forwards the bodies to main by transfer.
Protocol home (AD-10)New package protocol holds the concrete union (imports model, reactive); reactive keeps the generic machine; new fence and fixture.
Visible setfocus names a workspace; a table maps each workspace to its stages; the set is posted as one message at one seq.
Commands from snapshotsCarry their snapshot's seq; the register rejects a stale one with a typed rejection the editor shows briefly.
Lifecyclestage-started before each stage; past about 1 s the status strip shows the running stage with a Restart you choose; automatic restart only on a crash, with a new epoch and the whole value; "computing" until a stage's first post.
BuffersTransfer only buffers packed for that post; a crossing test posts twice and checks the worker's values.
Cycle check (AD-3)Declared reads are data in the blueprint version's declaration; the register checks read loops on main.
Wiring (AD-25)One partial per package per thread; each entry merges its own; dependency-cruiser fences per entry.
