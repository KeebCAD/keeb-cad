- (decision) [ADOPTED] Principles: explicit over terse; one way to do each thing; small coherent concept set.
- (decision) [ADOPTED] Tree = ownership. Position = anchor frame + local offset. Anchor = reference node + attach point (default origin); full frame (position+rotation), no position-only option; only free-group children and top-level groups set anchors; anchor graph acyclic.
- (decision) [ADOPTED] Single order of operations: offset applied in anchor frame, then rotate about pivot.
- (decision) [ADOPTED] Leaves are slots holding a part (switch cell, encoder, MCU, screw, empty). Empty slots still occupy their index. Index = position in a sequence.
- (decision) [ADOPTED] Arrangements: sequence (each child after previous: pitch along direction + gap + optional turn about pivot; drag changes that step, followers move; alt-drag compensates on next step) and free. No other arrangement types.
- (decision) [ADOPTED] Pitch (pitch-x/pitch-y) is a layout setting separate from switch type; switch type sets footprint + minimum pitch. Lengths carry units: u (resolved by pitch) or mm.
- (decision) [ADOPTED] Side mode: reversible (one geometry, no geometric overrides) | mirrored (derived copy across center group's vertical axis + named overrides: swap part, remove, offset).
- (decision) [ADOPTED] Outline is derived from the model, not authored.
- (decision) [ADOPTED] Glossary: anchor, attach point, offset, pivot, sequence, gap, free, slot, index, part, pitch, side, side mode, override. Each term means one thing.
- (decision) [ADOPTED] Product: changes reflected live in outline/PCB/case/firmware; complex routing in background with visible progress; never pretend autorouting solved. Key-cell templates per user. Curated add-ons. Remix via building-block library (saved model fragments), not KiCad import. KLE format rejected.
